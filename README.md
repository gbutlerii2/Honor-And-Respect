Application to dynamically read tombstone headers at military cemeteries such as Normandy and Arlington National linked to a comprehensive wiki-like 
database that allows for insertion, editing, and linking to military records of fallen soliders.

Users can scan a headstone or enter in a name and find the complete history of the person.  Can be be used for memorium, research, or curiosity.

Find it at https://www.honor-and-respect.com
